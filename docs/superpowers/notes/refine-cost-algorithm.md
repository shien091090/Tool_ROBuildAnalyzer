## 期望值模型

狀態 = 精煉度 k, `E[k]` = 從 k 到目標的期望成本向量(每種材料 + 本體件數各一分量), 用 Fraction 精確解線性方程組(各材料分量共用係數矩陣, 多 RHS 一次解):

- safe(100%): `E[k] = C_k + E[k+1]`
- minus1(失敗 -1): `E[k] = C_k + p*E[k+1] + (1-p)*E[k-1]`
- stay(祝福保護或特殊礦, 失敗原地): `E[k] = C_k/p + E[k+1]`
- break(失敗裝備消失): `E[k] = C_k + p*E[k+1] + (1-p)*(body + E[0])`

break 讓 E[0] 進入方程, 所有 E[k] 一起解。升階 = 幾何分佈期望次數 1/p, 每次嘗試消耗寶石 + 手續費(成敗都耗)。

## 已裁決規則(使用者定案, 不可自行更動)

1. +7~+14 預設一律用鐵匠的祝福(該區間有祝福選項時), 每次嘗試消耗規定數量, 成敗都耗
2. 鐵匠的祝福效果 = 失敗不消失也不降級(原地重試)
3. 裝備本體不計價, 以「期望需要幾件本體」呈現
4. 升階失敗裝備不消失
5. 升階成功後精煉歸 0 → 無→A 流程 = 4 輪(0→+11)精煉 + 各階升階嘗試, 最後再煉到目標值
6. 升階條件: 精煉 +11
7. 價值表填 0 就是 0, 不追問不推估
8. 兌換鏈遞迴展開到底(乙太寶石 → 乙太魔石 → 乙太星塵), 中間合成品數量另列供參考
9. 材料正名:「乙太粉塵」=「乙太星塵」, 統一叫乙太星塵
10. 乙太裝備 +14 以上無防護手段, 失敗就是消失(期望值天文數字是正確理論值)

1. 直接消耗(合成品層): 精煉材料 + 祝福 + 寶石 + 升階手續費 + 本體件數
2. 中間合成品(供參考): 如乙太魔石
3. 基礎材料攤開: 單價 × 數量小計、兌換手續費合計、升階手續費合計、總計 Zeny
