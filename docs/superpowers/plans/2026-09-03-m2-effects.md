> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把ROItemSearchApp的效果解析器移植為結構化輸出(EffectEntry), 建立「單件裝備(本體+卡片+附魔詞條)→整套配裝加總→兩套比較」的計算層, CLI可驗證, 無GUI。

**Architecture:** `app/core/`為純邏輯層(不依賴Qt)。解析器保留原版逐行掃描+if-chain+block_stack狀態機的控制流(移植保真優先), 但輸出層全面改為`EffectEntry`結構化條目; 除錯類輸出(📌✅❌⛔🟡)分流到trace清單或UNRECOGNIZED條目, **任何一層都不得重新解析上一層產生的顯示字串**(spec §5鐵則)。條件式效果引入「unresolved」機制: 條件運算觸及缺失的角色context時, 整個分支的原始行收進一筆UNRESOLVED條目(支撐UI「未計入的條件效果」區塊)。

**Tech Stack:** Python 3.11+(`py -3.12-64`), pytest, sqlite3。無新第三方依賴。
